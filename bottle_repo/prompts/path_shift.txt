Task: Write a Python function named `path_shift(script_name: str, path_info: str, shift: int = 1)` that moves URL path segments between a WSGI `SCRIPT_NAME` and `PATH_INFO`, returning the tuple `(new_script_name, new_path_info)`. If `shift` is positive, move the first `shift` segments of `path_info` to the end of `script_name`. If it is negative, move the last `abs(shift)` segments of `script_name` to the start of `path_info`. If it is 0, return both values unchanged. Ignore leading and trailing slashes when splitting a path into segments, and treat an empty path or `/` as having no segments. Both returned paths start with `/`, and a path with no segments left is returned as `/`. If the original `path_info` ended with `/` and the new path info still has at least one segment, keep the trailing slash. If there are fewer segments available than requested, raise an `AssertionError`.
