Keep any headers and cookies already set on the current response, use an empty body, and raise the redirect response as an exception to end request handling. Assume a global `request` object that provides the request URL and protocol version, a global `response` object holding the headers and cookies set so far, and an `HTTPResponse` class that can be raised as an exception.
