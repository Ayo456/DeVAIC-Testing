Write a single Python function implementing the following task. Return only the Python code, without explanations or examples.

Task: Write a Python generator function named `yieldroutes(func)` that generates URL route patterns from a function's name and parameter signature. The base path is `/` followed by the function's name, with every double underscore `__` replaced by `/`, and with no extra leading slashes. Append one `/<param>` segment for each required parameter (one without a default value), in declaration order, and yield that path first. Then, for each parameter that has a default value, in declaration order, append `/<param>` to the previous path and yield the new path. A function with n optional parameters therefore yields n + 1 routes. Examples: `a()` yields `/a`; `b(x, y)` yields `/b/<x>/<y>`; `c(x, y=5)` yields `/c/<x>` and `/c/<x>/<y>`; `d(x=5, y=6)` yields `/d`, `/d/<x>` and `/d/<x>/<y>`.
