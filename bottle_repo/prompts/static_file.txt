Task: Write a Python function named `static_file(filename, root, mimetype='auto', download=False, charset='UTF-8')` for a web framework that safely serves a file from inside the directory `root`. It returns (never raises) a response object. Assume a global `request` object exposing the WSGI environ and the request method, plus `HTTPResponse(body='', status=200, **headers)` and `HTTPError(status, body)` classes. Resolve `filename`, with leading and trailing slashes and backslashes removed, relative to `root`. If the resolved absolute path is not inside `root`, return a 403 error. If it does not exist or is not a regular file, return a 404 error. If it is not readable, return a 403 error. When `mimetype` is `'auto'`, guess the type from the file extension, and set `Content-Encoding` if the guess includes an encoding. If a MIME type is known, send it as `Content-Type`; for `text/*` types that do not already name a charset, add `; charset=<charset>` unless `charset` is empty. If `download` is true, set a `Content-Disposition: attachment` header whose filename is the file's base name; if `download` is a string, use that string's base name instead. Set `Content-Length` to the file size and `Last-Modified` to the file's modification time as an HTTP date in GMT. If the request has an `If-Modified-Since` header and the file has not been modified since that time, return a 304 response with these headers plus a `Date` header. For `HEAD` requests, use an empty body; otherwise, use the opened file in binary mode. Set `Accept-Ranges: bytes`. If the request has a `Range` header, return a 416 error when no requested byte range is satisfiable; otherwise, return a 206 response containing only the first satisfiable range, with `Content-Range: bytes <start>-<end>/<size>` (end inclusive) and `Content-Length` set to the range length. Otherwise, return a 200 response with the whole file.
