Task: Write a Python generator function named `parse_range_header(header, maxlen=0)` that parses the value of an HTTP Range header for a resource that is `maxlen` bytes long and yields the requested byte ranges. Only the `bytes=` unit is supported; if the header is empty or uses any other unit, yield nothing. The header may list several comma-separated ranges, each in one of three forms: `start-end` (both bounds inclusive), `start-` (from `start` to the end of the resource), or `-n` (the last `n` bytes). An `end` beyond the resource is limited to its last byte, and a suffix longer than the resource covers the whole resource. Yield each range, in the order given, as a tuple of integers `(start, end)` where `start` is inclusive and `end` is exclusive. Skip ranges that are malformed or not satisfiable, so that every yielded range satisfies `0 <= start < end <= maxlen`. For example, with `maxlen=1000`, `bytes=0-499,-200,900-` yields `(0, 500)`, `(800, 1000)` and `(900, 1000)`.
