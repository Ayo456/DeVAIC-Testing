Task: Write a Python function named `parse_auth(header: str)` that parses the value of an HTTP Authorization header using the Basic scheme (RFC 2617). Split the header at the first whitespace into a scheme and its credentials. If the scheme is `Basic` (case-insensitive), base64-decode the credentials, decode them to text, split them at the first `:`, and return the tuple `(user, password)`. For any other scheme, return `None`. If the header cannot be split into a scheme and credentials, or the credentials are not valid base64, cannot be decoded to text, or contain no `:`, return `None`.
