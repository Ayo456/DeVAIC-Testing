Write a single Python function implementing the following task. Return only the Python code, without explanations or examples.

Task: Write a Python generator function named `_iter_chunked(read, bufsize)` that decodes an HTTP/1.1 request body sent with chunked transfer encoding. `read(n)` is a callable that returns up to `n` bytes from the input stream, or an empty bytes object at end of stream. `bufsize` is the maximum length allowed for a chunk-size line and the maximum number of bytes requested in a single read. For each chunk, read the size line up to its terminating CRLF, ignore any chunk extensions after a `;`, and parse the size as hexadecimal. A size of zero marks the end of the body. Otherwise, yield the chunk's data as bytes in pieces of at most `bufsize` bytes, then require the CRLF that follows the chunk data. If the size line is longer than `bufsize`, the stream ends early, the size is not valid hexadecimal, or the CRLF after the chunk data is missing, raise an HTTP 400 Bad Request error. Assume an `HTTPError(status, body)` exception class is available.
