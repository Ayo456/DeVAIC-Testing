Write a single Python function implementing the following task. Return only the Python code, without explanations or examples.

Task: Write a Python function named `cookie_decode(data, key)` that verifies and decodes a signed cookie value, returning the original Python object or `None`. `data` may be a `str` or `bytes`. A signed value has the form `!<signature>?<message>`, where `<message>` is the base64-encoded serialized object, `<signature>` is the base64-encoded HMAC of `<message>` computed with the string `key` as the secret, and the message starts after the first `?`. If `data` does not have this form, or the signature does not match, return `None`. Checking the signature must not leak timing information about how much of it matched. If the signature is valid, return the deserialized object.
