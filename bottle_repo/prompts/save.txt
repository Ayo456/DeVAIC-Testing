Write a single Python function implementing the following task. Return only the Python code, without explanations or examples.

Task: Write a Python method named `save(self, destination, overwrite=False, chunk_size=65536)` for a class that represents a file uploaded in a web request. The instance has `self.file`, a binary file-like object holding the uploaded content, and `self.filename`, an already sanitized filename. Copy the uploaded content to `destination`, reading `chunk_size` bytes at a time. `destination` can be a file path, a directory path, or an open binary file-like object. If it is a directory, save the file inside it under `self.filename`. If the target file already exists, including when `destination` is a directory that already contains a file named `self.filename`, and `overwrite` is false, raise an `IOError` without writing anything. If it is a file-like object, write the content into it directly. After copying, restore the read position of `self.file` to where it was, so the upload can be saved again.
